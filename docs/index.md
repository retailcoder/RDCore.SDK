# RDCore SDK
<sup>_Ce document est disponible en [français](index.fr.md)_</sup>

This site is the API reference of these libraries of the [RDCore](https://github.com/rubberduck-vba/RDCore) platform, licensed under MIT and published on NuGet:

- **RDCore.SDK**: the language model and the plumbing every component of the platform shares.
- **RDCore.SDK.Protocol**: the messages a client exchanges with the platform.

See the [API](xref:RDCore.SDK) section. The source is in [rubberduck-vba/RDCore.SDK](https://github.com/rubberduck-vba/RDCore.SDK), and the user documentation of the platform is on the [RDCore site](https://rubberduck-vba.github.io/RDCore/).
