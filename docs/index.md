# RDCore SDK
<sup>_Ce document est disponible en [français](index.fr.md)_</sup>

This site is the API reference of **RDCore.SDK**, the language model and the plumbing every component of the [RDCore](https://github.com/rubberduck-vba/RDCore) platform shares, licensed under MIT and published on NuGet. The messages a client exchanges with the platform are in the [RDCore.SDK.Protocols reference](https://rubberduck-vba.github.io/RDCore.SDK.Protocols/).

See the [API](xref:RDCore.SDK) section. The source is in [rubberduck-vba/RDCore.SDK](https://github.com/rubberduck-vba/RDCore.SDK), and the user documentation of the platform is on the [RDCore site](https://rubberduck-vba.github.io/RDCore/).
