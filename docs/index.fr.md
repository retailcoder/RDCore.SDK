# RDCore SDK
<sup>_This document is available in [English](index.md)_</sup>

Ce site est la référence de l'API de **RDCore.SDK**, le modèle du langage et la plomberie que partagent tous les composants de la plateforme [RDCore](https://github.com/rubberduck-vba/RDCore), sous licence MIT et publiée sur NuGet. Les messages qu'un client échange avec la plateforme sont dans la [référence de RDCore.SDK.Protocols](https://rubberduck-vba.github.io/RDCore.SDK.Protocols/).

Voir la section [API](xref:RDCore.SDK). Le code source se trouve dans [rubberduck-vba/RDCore.SDK](https://github.com/rubberduck-vba/RDCore.SDK), et la documentation de la plateforme pour ses utilisateurs, sur le [site de RDCore](https://rubberduck-vba.github.io/RDCore/).
